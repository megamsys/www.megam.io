# Megam.io

Megam was an open-source cloud management and platform system built from
Chennai for operators running private and hybrid infrastructure. Rio/OS was the
second phase: a private-cloud operating-system direction whose public source of
record is now `github.com/rioos2`. This site exists because the code remained
open, the work mattered, and the old domain should explain what happened
instead of disappearing. [C003] [C027] [C032]
