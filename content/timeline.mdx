# Timeline

Megam had three phases: the Megam Systems phase, the Rio/OS phase, and the
October 2018 pivot. The dates below separate public evidence from founder-led
confirmation. [C001] [C003]

## Phase 1 - Megam, Jul 2012 to Jul 2017

### Jul 2012 - Megam project starts

Megam began as the project to build cloud identity for enterprise that became Megam Systems. The first project was https://github.com/megamsys/deccanplato and in the middle pivoted to code-to-cloud. The public site should
treat July 2012 as the project start and March 2013 as the company-registration
period unless a stronger registration source changes the wording. [C003]

### Mar 2013 - Megam Systems, Chennai

Megam Systems operated from Chennai, India. The public GitHub organization
still identifies the organization as Megam Systems and points to
`docs.megam.io`. [C003] [C004] [C051]

### 2014 - Megam's OpenNebula architecture became public

The OpenNebula material described Megam as a code-to-cloud system across
private, public, and hybrid clouds. The 2014 deck credited Varadarajan
Narayanan, Kishore Kumar Neelamegam, Thomas Alrin, and Raj Thilak, and listed
Java, Play, Ruby on Rails, Node.js, and Akka as supported frameworks. [C017]
[C018] [C019]

The same material included TOSCA, an OpenNebula Chef plugin, private cloud
installation, and Cloud-in-a-Box. This is the earliest public architecture
anchor for the closure site. [C020] [C021]

### 2014 - Docker Global Hack Day #2

Docker's archived Global Hack Day #2 results listed Visual Docker by Thomas
Alrin, Yeshwanth Kumar, and Rajthilak second by vote count among "Other projects
receiving top votes", with 457 votes. The public wording should cite the
Wayback capture and avoid the stronger phrase "2nd place global". [C025] [C026]

### Dec 2014 - OpenNebulaConf Berlin

OpenNebulaConf 2014 ran in Berlin from Dec 2-4, 2014. Kishorekumar Neelamegam
presented Megam Cloud Automation Platform there, and the talk remains one of
the primary public artifacts for the early system. [C022] [C023]

### 2015 to 2017 - Vertice, Nilavu, and the hosting-provider phase

Megam's public docs described MegamVertice as a platform for virtual machines,
apps, and containers. The docs named Nilavu as the console UI, the API gateway
as the API layer, and Vertice as the omni scheduler. [C007] [C011] [C013]

The product targeted operators running infrastructure such as OpenNebula,
OpenVZ, Docker, and Ceph, with WHMCS billing, storage, snapshots, logs, and
custom application flows in the product vocabulary. [C014] [C015] [C016]

Megam had 12 named Phase 1 customer accounts, confirmed by Kishore for public
use: Alternative-Energies.fr, Astimp.ro, AtomDeploy.com, FlexVPC, INTERGRID,
Jonathan Rack Servers, MilesWeb.com, QuadCloud, RioCorp, Simha Online, and TIC
Servicios. QuadCloud's update should be rendered with the QuadCloud entry
rather than as a separate customer. [C038] [C039] [C040]

## Phase 2 - Rio/OS, Jul 2017 to Oct 2018

### 2017 - Rio/OS begins

The public Rio/OS source for this site is `github.com/rioos2`. Kishore confirmed
that the Rio/OS GitHub organization is the public clone or sync of the private
Rio Advancement GitLab work, which is not available for public citation. [C027]
[C028]

Public Rio/OS repositories show Rust-era work in 2017 and 2018, including
`metgroup`, `nalperion_rust`, and `openio-sdk-rust`. Later GitHub timestamps
should be treated as synchronization or restoration dates, not original
development chronology. [C029] [C030]

### 2017 to 2018 - Rio/OS engagements

Rio/OS had CogMob as an enterprise pilot and ServerNet as a pilot enterprise
customer. Intergrid belonged to the Megam-era SMB pilot/customer story. DET.io
was associated with Megam only: a Megam partner, not a customer and not a Rio/OS
partner. [C041] [C042] [C043] [C061]

### 2018 - Rio Advancement

Megam Systems was acquired by Rio Advancement Inc., led by Paul Sanar. The
acquisition came with a promise of seed funding to extend Rio/OS development,
and that funding did not fully materialize. [C046] [C047]

## Phase 3 - Pivot, Oct 2018 onward

### Oct 2018 - Lendsmart / Getattune

Kishore met AK Patel, founder of Lendsmart, through Paul Sanar at a product
demo. In October 2018, the team relocated to Lendsmart / Getattune, and active
Megam/Rio/OS product development ended. [C048] [C049]

Kishore eventually became co-founder of Getattune. The closure event should be
written as a decision and a pivot, not as a slow decay. [C050]

### After 2018 - Open source remains

Megam and Rio/OS were fully open source and never really closed. The code
remains publicly useful as an artifact of what was built, even where individual
GitHub repositories have incomplete license metadata. [C032] [C033]

### 2026 - Closure site

The closure site replaces the old `www.megam.io` site with a public record of
what Megam and Rio/OS were, what shipped, who built them, and why active product
development ended. [C001] [C058]
