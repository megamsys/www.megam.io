# Colophon

This site replaces the old `megamsys/www.megam.io` website with a closure
record for Megam Systems and Rio/OS.

Build target: Next.js on Vercel.

Source repository: `github.com/megamsys/www.megam.io`.

The prose is intended to be published under CC-BY-4.0. Original code
repositories keep their original licenses; individual GitHub repositories may
show MIT, Apache-2.0, or incomplete license metadata, but Megam and Rio/OS were
fully open source overall.

The site is dark-only and uses the closure wordmark specified in the design
brief.

Corrections are welcome: <mailto:nkishore@megam.io>
