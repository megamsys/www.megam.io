# Artifacts

This manifest collects the public repositories, docs, talks, videos, and archive
folders tied to Megam and Rio/OS.

## Repositories

- [megamsys](https://github.com/megamsys) - Megam Systems public GitHub organization.
- [megamsys/nilavu](https://github.com/megamsys/nilavu) - browser UI for Megam PaaS / cloud management.
- [megamsys/verticegateway](https://github.com/megamsys/verticegateway) - MegamVertice API server.
- [megamsys/vertice](https://github.com/megamsys/vertice) - Megam Vertice core engine / scheduler.
- [megamsys/gulp](https://github.com/megamsys/gulp) - lifecycle agent.
- [megamsys/opennebula-go](https://github.com/megamsys/opennebula-go) - OpenNebula Go client used by Megam Vertice.
- [megamsys/megam_api](https://github.com/megamsys/megam_api) - Ruby API client.
- [megamsys/megam_common](https://github.com/megamsys/megam_common) - shared Scala libraries.
- https://github.com/megamsys/gitpackager
- [rioos2](https://github.com/rioos2) - public Rio/OS source clone/sync.
- [rioos2/rioos](https://github.com/rioos2/rioos) - issue and resolution tracker for Rio/OS.
- [rioos2/commandcenter](https://github.com/rioos2/commandcenter) - Rio/OS command center.
- [rioos2/autorio](https://github.com/rioos2/autorio) - Rio/OS automation work.
- [rioos2/aran](https://github.com/rioos2/aran) - Rio/OS system component.
- [rioos2/beedi](https://github.com/rioos2/beedi) - Rio/OS system component.
- [rioos2/ottavada](https://github.com/rioos2/ottavada) - Rio/OS system component.
- [rioos2/magudi](https://github.com/rioos2/magudi) - Rio/OS support/tooling component.
- [rioos2/kr](https://github.com/rioos2/kr) - Rio/OS support/tooling component.
- [rioos2/poochi](https://github.com/rioos2/poochi) - Rio/OS support/tooling component.
- [rioos2/openio](https://github.com/rioos2/openio) - OpenIO-related support work.
- [rioos2/vulcand](https://github.com/rioos2/vulcand) - load-balancer support work.
- [rioos2/metgroup](https://github.com/rioos2/metgroup) - support library for metrics aggregation.
- [rioos2/nalperion_rust](https://github.com/rioos2/nalperion_rust) - reference library for Nalpeiron licensing integration.
- [rioos2/openio-sdk-rust](https://github.com/rioos2/openio-sdk-rust) - support library for S3-compatible OpenIO access.

Repository counts are approximate because public GitHub views and API pagination
can differ.
